📝 Todo List Application (Node.js)

A simple and elegant Todo List web application built using Node.js, Express, and EJS.
This project allows users to create, view, update, and delete todos with a clean UI and smooth user experience.

🚀 Features

➕ Add new todo with title, description, category, and status

📝 Edit existing todos

❌ Delete todos

📌 Track todo status (Pending / In Progress)

🎨 Modern UI with smooth layout and styling

🧭 Easy navigation between list, add, and edit pages

🖥️ Project Preview

The application includes:

Todo List Page – View all todos with Edit & Delete options

Add Todo Page – Create a new todo using a form

Edit Todo Page – Update existing todo details

🛠️ Tech Stack

Backend: Node.js, Express.js

Frontend: EJS, HTML, CSS, JavaScript

Styling: Custom CSS

Architecture: MVC pattern (Controllers & Routes)

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/pragati1112/Nodejs_TodoList.git


Navigate to project directory:

cd todo-app-node


Install dependencies:

npm install


Start the server:

node index.js


Open browser and visit:

http://localhost:3000

📌 Usage

Click Add New Todo to create a task

Use Edit to update todo details

Use Delete to remove a todo

Status helps track task progress easily
